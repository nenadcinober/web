# Stranica za prikaz jela i kalorija

Stranica prikazuje jela i namirnice koje su poznate i često se koriste u podravini

Koristi jedinstven dizajn

O svakoj namirnici se može otvoriti posebna stranica s detaljima i prikazom kalorija

Na vrhu stranice se nalazi box za unos teksta gdje se mogu upisati namirnice i tako se kreira lista namirnica i automatski se kalkuliraju kalorije za tu listu
